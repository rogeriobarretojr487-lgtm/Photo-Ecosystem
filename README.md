# Photo Ecosystem — Jovi (FIAP Challenge, Sprint 2)

Front-end da solução Photo Ecosystem: um ecossistema de fotos e conexões entre usuários de smartphones Jovi.

**Turma:** 1TDSOE — Análise e Desenvolvimento de Sistemas

## Stack

HTML, CSS, JavaScript e Tailwind CSS (via CDN). Nenhuma outra tecnologia, conforme o escopo do challenge.

## Estrutura

```
index.html        # onboarding / entrada
pages/            # telas do app
assets/css/       # estilos próprios (cores da marca)
assets/js/        # scripts (navegação, interações)
assets/img/       # imagens
docs/             # apresentação em PDF e material da Sprint 1
```

## Telas

| Arquivo | Tela |
| --- | --- |
| `index.html` | Onboarding — "Compartilhe momentos" |
| `pages/feed.html` | Feed interativo |
| `pages/stories.html` | Stories e momentos temporários |
| `pages/busca.html` | Pesquisas e sugestões |
| `pages/mapa.html` | Mapa e GPS |
| `pages/galeria.html` | Galeria de pontos turísticos |
| `pages/perfil.html` | Perfil de usuário |
| `pages/config.html` | Configurações, privacidade e segurança |

## Como rodar

Abrir `index.html` no navegador. Não há build nem dependências para instalar.
